Cada regla tiene nombre.

CREATE TABLE detalle_pedido (
  pedido_id        INTEGER        NOT NULL,
  producto_id      INTEGER        NOT NULL,
  cantidad         DECIMAL(10,2)  NOT NULL,
  precio_unitario  DECIMAL(10,2)  NOT NULL,
  CONSTRAINT pk_detalle_pedido
    PRIMARY KEY (pedido_id, producto_id),
  CONSTRAINT fk_detalle_pedido_pedido
    FOREIGN KEY (pedido_id) REFERENCES pedido
    ON DELETE CASCADE,
  CONSTRAINT fk_detalle_pedido_producto
    FOREIGN KEY (producto_id) REFERENCES producto
    ON DELETE RESTRICT,
  CONSTRAINT ck_detalle_pedido_cantidad_positiva
    CHECK (cantidad > 0)
);
CREATE INDEX idx_detalle_pedido_producto_id
    ON detalle_pedido (producto_id);

Cuando una regla falla, el error la nombra y la API lo convierte en un 400 o 409 claro. El mismo esquema existe para SQLite y MySQL.

Lo que nos costó.

stock = stock − x en SQL más CHECK >= 0. Probado con 50 hilos.
